# Manifest for tools/gen_dashboard_icons.sh - production weather-condition
# icons for the Dashboard screen (src/dashboard_ui.cpp), one line per
# generated image, pipe-delimited:
#   lvgl_name|source_svg|size_px
#
# lvgl_name   - must be a valid C identifier, unique across the file.
# source_svg  - path to a .svg under docs/mockups/assets/icons/, relative
#               to the repo root. sun/cloud/rain/moon are verbatim
#               extractions of the mockups' own inline icon SVGs; every
#               other icon is an original design added later, no mockup
#               reference for these - see each .svg's own header
#               comment, and include/weather_icon.h for the bucketing
#               logic that maps API condition types to these 15 icons.
# size_px     - square render size, passed to rsvg-convert as both -w/-h.
#
# Two sizes per icon: kIconSizeHero (the "now" section's condition glyph,
# dashboard_ui.cpp) and kIconSizeDayRow (the 7-day outlook's per-row
# icon) - matches the mockup's own two icon footprints (.glyph vs.
# .day-row .icon in dashboard.html's CSS).
#
# Order matches WeatherIconBucket's declaration order in
# include/weather_icon.h - dashboard_ui.cpp's iconForBucket() looks up
# by that enum's index, not by name, so keep the two in sync if either
# changes.
