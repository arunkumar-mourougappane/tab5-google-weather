# Manifest for tools/gen_font_gallery.sh - one font/size to generate per
# line, pipe-delimited:
#   lvgl_name|source_font|size_px|symbols|sample|caption
#
# lvgl_name   - must be a valid C identifier, unique across the file.
# source_font - path to a .woff2/.ttf/.otf, relative to the repo root.
#               .woff2 sources are cached and converted to .ttf once per
#               distinct path, even if reused across multiple lines.
# size_px     - passed straight to lv_font_conv --size.
# symbols     - passed straight to lv_font_conv --symbols. Keep subsets
#               narrow (see docs/rendering.md's flash-budget point) -
#               this isn't meant to hold a full Latin charset per size
#               unless the entry specifically needs one (e.g. a label
#               readability test, not a digit-only hero number).
# sample      - text shown on-device in this entry's font. Must only use
#               characters included in `symbols`, or LVGL falls back to
#               its default font (or blank tofu) for whatever's missing.
# caption     - shown on-device under the sample text.
#
# Add a line and rerun tools/gen_font_gallery.sh to test another
# size/family/subset - no code changes needed.
