Tab5 · Google Weather

Screen mockups

Six screens covering the full loop a wall-mounted weather kiosk needs: first-run setup, the default dashboard, two detail drill-downs, the states that show up when things go wrong, and a severe-alert takeover. Click any card to open it full-size and interactive (day/night toggle included).

All six share one design system — assets/style.css — so a token change (palette, type scale) here previews consistently everywhere at once. See docs/rendering.md for how this maps to actual LVGL widgets.
