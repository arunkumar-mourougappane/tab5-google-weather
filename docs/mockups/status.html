Tab5 · Google Weather — Screen 4

Boot, sync, and offline states

A kiosk has no console to check when something's wrong, so these three states are part of the UI, not an afterthought: connecting to WiFi at boot, first fetch, and — the one that matters most — what happens when the network or the API is unreachable. We show the last-known reading, dimmed, rather than a blank or frozen screen.
