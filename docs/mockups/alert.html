Severe alert: overlays the dashboard, doesn’t replace it

The Weather API's alerts data surfaces as a banner over a dimmed dashboard, not a full-screen swap — current conditions stay visible underneath. A dedicated alert red is used only here, kept apart from the brass/teal/ember accents used everywhere else, so it reads as urgent precisely because the rest of the UI never uses that color.
