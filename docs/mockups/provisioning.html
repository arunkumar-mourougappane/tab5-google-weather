Tab5 · Google Weather — Screen 6

First-run provisioning: the display side and the setup page

No keyboard on the kiosk, so it can't take Wi-Fi credentials, a location, or a Google API key directly. On first boot (or after a long-press reset) it opens its own access point and shows a join code; connecting to that network opens a small setup page — served by the device itself — to collect the three things it needs.
